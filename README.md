# KONTUR / OnePage Checkout 2.5.3

Модуль швидкого оформлення замовлення для **ocStore / OpenCart 3.0.4.1** (гілка 3.x).
Замінює стандартну сторінку `checkout/checkout` на одну сторінку: контакти, доставка, оплата, кошик.

Архів для установника: `kontur_checkout_ocstore_3.0.4.1_v2.5.3.ocmod.zip`

## Встановлення

1. Адмін-панель → **Розширення → Установник** → завантажити zip.
2. **Розширення → Модифікації → Оновити** (синя кнопка).
3. **Розширення → Розширення → Модулі** → **KONTUR / OnePage Checkout** → **Встановити** → **Редагувати**.
4. Налаштування відкриваються на весь екран. Натисніть **Зберегти**.

Оновлення поверх уже встановленого модуля: завантажте новий zip тим самим установником. Модуль видаляти не потрібно — інакше зітруться налаштування. Після оновлення відкрийте модуль → **Інтеграції** → **Завантажити базу**.

Стилі вітрини лежать у `catalog/view/javascript/kontur_checkout/checkout.css`. Установник OpenCart 3 не дозволяє запис у `catalog/view/stylesheet`.

Поки статус модуля **Увімкнено**, маршрут `index.php?route=checkout/checkout` віддає цю сторінку.
Кнопка «Оформити» в кошику лишається стандартною — модуль перехоплює контролер.

Щоб повернути стандартне оформлення: у шапці конфігуратора вимкніть статус і натисніть **Зберегти**, або видаліть модуль.

## Що вміє

- Конструктор полів покупця (тип, placeholder, ширина 50/100, обов’язковість, порядок, свої поля).
- Доставка: Нова Пошта (відділення/поштомат і кур’єр), Укрпошта, самовивіз. Тариф і поріг безкоштовної доставки.
- Спочатку служба або спочатку адреса. Швидкі міста.
- Оплата і матриця «доставка ↔ оплата» (картка, післяплата, IBAN/ЄДРПОУ, готівка в шоурумі).
- Сітка 62/38, 50/50 або одна колонка. Мобільний патерн: акордеон + sticky, компактний список, лише sticky.
- Промокоди магазину OpenCart і вбудовані демо-коди `SALE10` (−10%) та `GIFT1000` (−1000). Подарункове пакування +95.
- Вхід постійного клієнта в акаунт OpenCart, маска телефону +38, перевірка кодів операторів UA.
- Довідник відділень Нової Пошти. У вкладці «Інтеграції» вставте API-ключ (32 символи) і натисніть **Завантажити базу**. Міста й відділення зберігаються в таблицях магазину, оформлення бере їх звідти. Створення ТТН немає. Поки база порожня, для справжнього ключа лишається живий запит `Address.getWarehouses`, інакше показується короткий локальний довідник.
- Довідник відділень Укрпошти. Той самий блок **Інтеграції**: Bearer адресного класифікатора (UUID з кабінету Укрпошти) і **Завантажити базу**. Відділення пишуться в базу магазину, на оформленні обираються зі списку, індекс підставляється сам. Створення відправлень немає. Без бази лишається ручне поле індексу і відділення.
- 6 дизайн-тем, кольори, шрифти, стиль полів і секцій, радіус, товщина ліній, свій CSS.
- Замовлення створюється штатним `model_checkout_order` (товари, підсумки, лист, списання складу за статусом).
- Події analytics: `dataLayer` GA4 і `fbq`, якщо піксель уже стоїть на сайті. Checkbox / mono / WayForPay — прапорці в конфігурації (оплата в концепті підтверджується на цій сторінці, без редіректу в шлюз).

## Мови

Інтерфейс оформлення — українською, як у макеті. Назва модуля в списку розширень є для `uk-ua`, `ru-ru`, `en-gb`.
